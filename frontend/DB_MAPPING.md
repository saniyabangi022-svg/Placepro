# PlacePro - UI to Database mapping (rpms_db, 17 tables)
| Page | Tables used |
|---|---|
| Login | users, roles (username or email + role) |
| Dashboard / Reports | candidates, jobs, applications, interview_rounds, offers, placements, companies, users, activity_logs |
| Candidates / form / details | candidates, candidate_skills, skills, qualifications, locations |
| Companies | companies |
| Jobs / form | jobs, job_skills, skills, companies, users(created_by) |
| Applications | applications, application_history, candidates, jobs, users(recruiter) |
| Interviews | interview_rounds (application_id, round_number unique per application) |
| Placement Process | interview_feedback (1 per round), offers (1 per application), placements (1 per offer) |
| Activity Log | activity_logs |
Notes: codes (CAN-, COM-, JOB-, APP-, OFR-) are generated by the backend; INT-/PLC- are display forms of numeric ids. Ratings are 0-5 (DB CHECK). Job technology/skills live in job_skills. Dates in the UI are display format; DB stores ISO.
